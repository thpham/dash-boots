# Dash Boots

An original 16-bit style platformer. The whole game simulation lives in Rust,
compiled to WebAssembly; a thin TypeScript/Vite layer handles assets, input,
WebGL2 and WebAudio.

**Play online, free:** https://thpham.github.io/dash-boots/ — the site is built
and published by GitHub Actions on `v*` tags (deploy-pages workflow).

## What's in this repo

| Path | What it is |
|---|---|
| `snes-wasm/` | The game (simulation crate, web platform layer, level) |
| `snes-wasm/wasm/` | Rust crate compiled to WASM (physics, rules, Tiled parser, bot) |
| `snes-wasm/tools/` | Stdlib-only Python generators for the original art, audio and level |
| `flake.nix` | The dev environment (rust, wasm-pack, node, chromium) — used identically in CI |
| `.github/workflows/` | Publishing CI: GitHub Pages deployment on `v*` tags |

Assets and levels are all original and generated by the Python tools; the level
file is a regular [Tiled](https://www.mapeditor.org/) map you can edit.

## Run locally

The nix flake provides the exact environment (same in CI). With direnv enabled,
or `nix develop` first:

```bash
just dev        # dev server, http://localhost:5173
just serve      # production build served at http://localhost:4173
just check      # lint + tests + build + browser smoke test
```

Full documentation — controls, gameplay, Tiled conventions, tasks — lives in
[`snes-wasm/README.md`](snes-wasm/README.md).
